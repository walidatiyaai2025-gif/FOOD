# Foodx integration map

The mockup is intentionally standalone. When approved, map these screens to the existing Foodx domains instead of creating duplicate restaurant truth.

| Mockup surface | Foodx integration target |
|---|---|
| Marketplace home restaurant section | New restaurant discovery projection over eligible Smart Ordering sites |
| Restaurants list/filter/search | Restaurant discovery API + location/open state |
| Restaurant detail/menu | Existing Smart Ordering published menu API |
| Meal details/options | Existing Smart Ordering item quote/modifier contracts |
| Restaurant cart | Existing Smart Ordering cart endpoints |
| Checkout | Existing Smart Ordering CheckoutService; Foodx customer login handoff |
| Orders | Canonical Foodx order/customer history |
| Tracking | Existing Smart Ordering lifecycle/tracking data |
| Offers | Existing Smart Ordering merchandising/offers |
| Favorites | Customer account preference surface |
| Notifications | Existing Foodx customer notifications |
| Contact us | Existing CRM customer-service case endpoint |

No MenuV2, OrderV2, second restaurant ledger, or second QR engine is needed.
