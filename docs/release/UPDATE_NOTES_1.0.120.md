# FOODEX 1.0.120 Update Notes

- Driver saved biometric session switches the login screen to fingerprint/biometric unlock and Sign out only; email, password, regular Sign in and onboarding toggles are hidden until session logout.
- B2B and B2C Driver Remember Me secure session restoration is supported, with no plaintext password persistence.
- Existing Driver Wallet and Home / Wholesale Deliveries premium UI are integrated without changing source-of-truth financial, delivery or authorization behavior.
- Customer, Driver and Van app identities are synchronized at `1.0.120+120`; Dashboard Update and Laravel Setup must be rebuilt from the same final main source using the canonical Release Factory.
