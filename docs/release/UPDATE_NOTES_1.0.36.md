## Included changes

- One Platform Customer address book shared safely across Wholesale and Retail contexts.
- Manual address entry plus explicit foreground location sharing and corrected map-pin selection; no background tracking is introduced.
- Backend-owned checkout validation and immutable delivery-address snapshotting on each order.
- Customer 360 address create/edit/delete/default controls and Order Operations delivery-location/map visibility.
- Driver assignment payloads include immutable delivery coordinates and a safe external-navigation action.
- Backend-authoritative Customer/Driver lifecycle push notifications with deep-link metadata, deduplication, retry/backoff, invalid-token cleanup and durable delivery logging.
- Stable per-installation push identity across FCM token refresh, explicit logout revocation and multi-device preservation.
- Foreground/local notification taps and cold-launch routing for Customer and Driver.
- Arabic/English mobile screenshot evidence plus Admin Customer360/order-location runtime screenshots.
