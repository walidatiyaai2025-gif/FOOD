## Included Dashboard changes

- Fix the FOODEX Assistant External AI API-key save failure on MySQL. The encrypted key is now persisted as valid JSON in `settings.value`, remains encrypted at rest and is decoded only for decryption at runtime.
- Include the latest global Admin header alignment for search, notifications and account controls.
- Include the P0 Retail authentication fix that prevents cross-account lockout after a failed Retail login attempt.
- Add authoritative B2C business profiles so Retail Store and Restaurant contexts can diverge cleanly under explicit server-side profile rules.
- Carry forward every earlier 1.0.89 capability already merged into main, including Restaurant SaaS, Customer Service, enterprise administration and configurable Assistant provider settings.
