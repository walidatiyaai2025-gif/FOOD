# FOODEX 1.0.114 — Synchronized Dashboard and Mobile Release Notes

## Included changes

- Make Customer, Driver and Van Firebase device registration self-healing after reinstall, transient registration failure and FCM token rotation.
- Re-register push devices on authenticated app resume; Customer also restores guest push registration when unauthenticated.
- Use bounded registration retry/backoff instead of silently leaving a logged-in app without an active push device.
- Keep explicit logout revocation and backend user/app/channel authorization unchanged.
- Increase the Driver Home delivery workload distribution card height by exactly 20% while preserving the fixed no-scroll Home layout.
- Add a full-width Driver Home card for total unsettled collections, sourced from the authoritative Driver custody wallet.
- Expose `unsettled_collections` in the Driver wallet API as the current custody amount not yet settled by Finance.
- Add a Dashboard Finance Support summary for unsettled Driver collections grouped by currency from the same custody ledger.
