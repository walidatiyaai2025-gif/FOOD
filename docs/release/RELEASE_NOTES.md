# FOODEX 1.0.117 — Synchronized Release Notes

- Dashboard / repository release: `1.0.117`.
- Customer App: `1.0.117+117`.
- Driver App: `1.0.117+117`.
- Van App: `1.0.117+117`.

## Included changes

- Repair existing-database Customer Service dispatch authorization so the canonical Customer Service roles receive `orders.dispatch` and the Order Management Driver/Van assignment controls remain available after upgrade.
- Add administrator-managed per-user permission overrides with explicit allow/deny semantics layered over role defaults.
- Preserve SUPER_ADMIN protections and enforce global/store/channel authorization boundaries for every override.
- Reset individual overrides when role assignments change and reconcile canonical RBAC database state around permission mutations to remove stale built-in role/permission data.
- Self-heal the per-user override marker from authoritative override rows during reconciliation.
- Preserve the pre-override targeted permission-query path for ordinary users with no overrides, preventing RBAC functionality from increasing WMS query budgets.
