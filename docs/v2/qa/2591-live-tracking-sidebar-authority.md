## Placement and real business capability

Reuse the **existing** Management Dashboard Operations > Live Tracking destination, not a separate screen or new sidebar item. Canonical key: driver_live_tracking in AdminNavigation::groupsFor. Canonical route: admin.driver-live-tracking.index. The accessible page provides the live map, localized status/empty/loading/errors, retry control, authorized store selector, scoped human-readable driver/van/order/route lookups, existing feed and protected tracking actions. Route parameters are generated by Laravel, not untrusted saved visibility rows.

Permission drivers.tracking.view is evaluated by the real User permission/scope model and DriverLiveTrackingDashboardController. The controller uses OperationalTenantScope for per-store/channel lookup data. This page's availability is not an independent enterprise module entitlement toggle; no fabricated module gate, grant or readiness state is introduced. The existing Sidebar group remains Operations; the full synchronized fleet map and its B2B Van-only/B2C Driver-only semantics are unchanged.

Navigation owner: Dashboard Operations group; route and permission source: AdminNavigation, Laravel named routes, tracking controller, and OperationalTenantScope. Reuse existing desktop and responsive mobile-web page with AR/EN and RTL/LTR. Fallback/back path: existing Dashboard Operations navigation. No DIRECT_URL_ONLY workflow, new menu structure or new UI copy.
