# V2 #3520 — Web installer PHP extension preflight

- **Source:** P112 / G004 #2745, P112 #2846, master #2503.
- **Isolation:** issue-scoped branch `fix/3520-v2-installer-required-extensions`, PR base `Foodex_V2` only. No main, tags, production or deployed ZIP.
- **Observed source gap:** the existing server-requirement check lists core PHP extensions and MySQL PDO but omits `zip` and `fileinfo`. The Admin Update ZIP validator requires `ZipArchive`, and uploaded file MIME inspection relies on `fileinfo`; without early detection an installation can finish on an incompatible shared host.
- **Fix:** the ordered canonical required extension list includes `zip` and `fileinfo`. The existing `installer.errors.extension` translation is reused in Arabic and English. The specialized `pdo_mysql` diagnostic is preserved. An optional server-side extension-availability callback lets tests simulate missing extensions; normal HTTP installation always uses the actual `extension_loaded` runtime check.
- **Focused test:** `backend/tests/Feature/V2InstallerExtensionPreflightTest.php` checks canonical requirements, simulated missing ZIP and fileinfo in both locales, all-present success, and specialized `pdo_mysql` failure. Existing `InstallerWorkflowTest.php` protects the 15-step wizard's success and failure paths.
- **Safety:** the requirements check occurs at web installation step 2, before database configuration, APP_KEY, seeding, uploads or version lock. No new route, UI locale key, auth rule, tenant scope, migration, package, or external action. Existing error shape remains unchanged.
- **App impact matrix:** Backend installer affected; Dashboard retains original update behavior and now benefits from prereq validation before installation. Customer: not affected; Driver: not affected; Van: not affected. No public API or Flutter contract changed. B2B=Van-only / B2C=Driver-only unaffected.
