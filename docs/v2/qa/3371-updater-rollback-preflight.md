# V2 #3371 — fail-closed file rollback backup preflight (P112 / G005)

- **Source:** FOODEX Unified RBAC/ERP/Sidebar 2026-11-09, P112; parent #2746 G005, #2846 and #2503.
- **Target:** isolated `Foodex_V2` only. No main, release/tag, APK/ZIP publication, production, or cPanel access.
- **Behavior before:** `LaravelUpdateRuntime::rollbackFiles()` removed all `targets` before checking whether `existing` backup file sources were complete/readable. One missing original after another target could leave both upgraded files deleted without restoration. Untrusted symlink backup sources were copied, and out-of-target metadata was not rejected until after deletion.
- **Behavior after:** validate nonempty full manifest, canonical unique targets, existing membership and uniqueness, all release paths, private backup path components and readable regular original backup files *before any live deletion*. Reject corrupt/partial/linked input with path-free errors; support zero-byte originals. Preserve the existing restore order and valid rollback behavior. Tests use isolated synthetic paths; no live user data touched.
- **Regression commands:** `cd backend && php artisan test --filter=V2UpdaterRollbackPreflightTest` and `php artisan test --filter=V2UpdaterDuplicateArchiveTargetsTest`; exact-head required CI must also run full Laravel, security, MySQL/Redis installation/upgrade/recovery and AR/EN validations.
- **Test matrix:** missing second backup after first target; unrelated existing metadata path; symlinked private backup file; duplicate targets; successful restore of original and zero-byte original while removing newly introduced file.
- **Access and UI:** Existing authenticated Super Admin updater/recovery flow, routes, entitlements and audit are unchanged. No new Dashboard screen, permission or user-visible text. Existing AR/EN behavior and responsive views remain unchanged.
- **Mobile impact:** Customer **NOT AFFECTED** — no public API/Flutter/storage contract changes. Driver **NOT AFFECTED** — no assignment, B2C delivery, API or Flutter change. Van **NOT AFFECTED** — no B2B custody, visits, API or Flutter change. B2B = VAN ONLY, B2C = DRIVER ONLY preserved.
- **Limitations:** A successful preflight is not a guarantee against storage/media failure or a racing filesystem mutation during restoration; this change does not certify database rollback, original backup cryptographic authenticity, real signed ZIP, or end-to-end recovery. These remain part of open parent gates #2746/#2846/#2503.
- **Acceptance:** issue-scoped branch `fix/3371-v2-rollback-file-backup-preflight`, exactly one Foodex_V2 PR; check Repository Policy, FOODEX V2 Isolation Gate and FOODEX Required CI Gate on final exact head, inspect diff and mergeability before merge. Close only atomic #3371 if proven green/merged. Do not claim complete updater release certification.
