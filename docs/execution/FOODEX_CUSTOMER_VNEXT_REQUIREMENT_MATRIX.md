# Customer VNext Requirement-to-Evidence Matrix

Authority: [execution plan](FOODEX_CUSTOMER_VNEXT_EXECUTION_PLAN.md), [Umbrella #1323](https://github.com/walidatiyaai2025-gif/FOOD/issues/1323) and AGENTS.md §26.

This matrix defines required product evidence; **OPEN is not a cached Issue/PR status**. A closed Issue or green CI alone never changes a row to PASS. The owning lane supplies source/test/runtime evidence; #1333 reviews the integrated exact source and records the final verdict. Source/seed/image work belongs to #1330; reset to #1331; Launch to #1332. #1334 only freezes this plan/manifest/matrix and does not certify the product.

All UI rows require AR RTL and EN LTR, representative small/standard/large Customer phones, and Dashboard 320/390/768/1024/1280 where applicable. Applicable loaded/empty/error/offline/slow/long-text/missing-image/out-of-stock states and real route interactions must be captured. Data-only checks require no separate UI screenshot; their consuming product routes still require visual proof.
