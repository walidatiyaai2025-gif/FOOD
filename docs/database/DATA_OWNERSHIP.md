# Data Ownership

Platform-global data includes roles, permissions, master product definitions, system versions, update history and global settings.

Store-scoped data includes store products, inventories through assigned warehouses, store promotions/banners, retail orders and store reports.

Customer-owned access includes addresses, cart and order history through authenticated policy checks.

B2B-owned access includes approved business account, price tier and wholesale financial documents.

Driver access is limited to assignments authorized for the driver's exact driver type. No B2C/B2B crossover.

Client-supplied store IDs are never sufficient authorization; every query must resolve scope server-side.
