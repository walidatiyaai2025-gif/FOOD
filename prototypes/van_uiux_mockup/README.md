# FOODEX Van UIUX Mockup Lab

This branch contains a design-only standalone prototype for reviewing the FOODEX Van application.

It is intentionally isolated from production application code:
- fake visual data only
- no backend or API calls
- no real authentication
- no operational permissions or side effects
- no database or release coupling
- Arabic and English UI
- FOODEX visual identity
- compact mobile layout

Included mock screens:
1. Login
2. Home dashboard
3. Routes
4. Route map
5. Route detail
6. Customers
7. Visit workspace
8. Customer 360
9. Product catalog
10. Order builder
11. Order review
12. Orders
13. Offers
14. Wallet
15. Collection
16. Receipt
17. Remittance
18. Notifications
19. Profile and settings

The opening screen is a design gallery so every screen is directly reachable.
